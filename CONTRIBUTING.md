# Contributing to Bitcoin Deepa

Thank you for helping build Bitcoin — the *Pearl of Satoshi* — for Sri Lanka.
Contributions of every kind are welcome: code, Sinhala and English docs,
translations, design, testing, and teaching materials.

## Our principles

- **Plain language.** Explain Bitcoin in everyday words; briefly explain any
  technical term.
- **Bilingual.** Sinhala and English stand side by side. Docs and UI strings
  should aim for both where it makes sense.
- **Self-custody and safety first.** We handle people's money and keys. Code that
  touches funds, wallets, or Lightning must be reviewed with extra care.
- **No hype.** Honest, calm, and useful — never "get rich with crypto."

## Ways to contribute

- **Report a bug** or **request a feature** — open an issue using the templates.
- **Improve docs or translations** — even a small Sinhala wording fix helps.
- **Write code** — pick an open issue, or propose a change first for anything large.
- **Join the discussion** — [Telegram community](https://t.me/BitcoinDeepa).

## Development workflow

1. **Fork** the repository and create a branch from `main`
   (e.g. `fix/wallet-balance`, `feat/dca-schedule`).
2. Make your change. Keep commits focused and write clear messages.
3. Add or update tests and docs where relevant.
4. Run the project's linters/tests locally (see each repo's `README`).
5. Open a **pull request** against `main` and fill in the PR template.
6. A maintainer will review. Please be patient and responsive to feedback.

## Commit sign-off (DCO)

By contributing, you certify the [Developer Certificate of Origin](https://developercertificate.org/).
Sign off each commit:

```bash
git commit -s -m "feat: add Sinhala onboarding strings"
```

## Licensing of contributions

Unless a repository states otherwise, contributions are accepted under the same
licence as that repository (**AGPL-3.0**): inbound = outbound. You keep copyright
in your contribution and licence it to the project under that licence. Do **not**
contribute code you do not have the right to submit.

Note: the Bitcoin Deepa **brand and logo assets** are proprietary and are not part
of the open-source grant — see [TRADEMARK.md](./TRADEMARK.md).
