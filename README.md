# .github

This repository holds the organisation profile and community health defaults for Bitcoin Deepa — Pearl of Satoshi.

The public profile page lives in [profile/README.md](profile/README.md). The community health files —
CODE_OF_CONDUCT.md, CONTRIBUTING.md, SECURITY.md, SUPPORT.md, TRADEMARK.md, the issue templates and the pull
request template — apply across the whole organisation unless a repository provides its own.

[TRADEMARK.md](TRADEMARK.md) and the [brand guidelines](https://bitcoindeepa.com/brand).
